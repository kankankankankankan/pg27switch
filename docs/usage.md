# macOS Usage

`pg27switch` uses BetterDisplay to send the PG27UCDM input selection command. It shows a native HUD on every connected display, counts down, and lets you cancel with `ESC`.

## Requirements

- macOS 12 or later
- BetterDisplay at `/Applications/BetterDisplay.app`
- DDC enabled for the PG27UCDM in BetterDisplay

## Build and Install

```bash
./macos/build.sh
./macos/install.sh
```

The installed command is:

```text
/usr/local/bin/pg27switch
```

## Inputs

```text
dp, displayport          DisplayPort  15
h1, hdmi1                HDMI 1       17
h2, hdmi2                HDMI 2       18
tc, typec, usb-c, usbc   Type-C       26
```

## Common Commands

```bash
pg27switch dp
pg27switch hdmi1
pg27switch --preview hdmi1
pg27switch --input dp --seconds 5
pg27switch --name "HDMI 1" --value 17
pg27switch --help
```

`--preview` does not call BetterDisplay. `--seconds` accepts values from 1 to 30 and defaults to 3.

For a custom BetterDisplay path:

```bash
pg27switch hdmi1 --betterdisplay /Applications/BetterDisplay.app/Contents/MacOS/BetterDisplay
```

## Stream Deck

Use Mac Script Runner with language `Zsh`, or bind the `.command` files generated by `macos/install.sh` with `System > Open`.

Example:

```zsh
/usr/local/bin/pg27switch hdmi1
```

Use preview mode while configuring buttons:

```zsh
/usr/local/bin/pg27switch --preview hdmi1
```

## Logs

```text
~/Library/Logs/PG27UCDMSwitcher/pg27switch.log
```

If the monitor does not switch, verify DDC access in BetterDisplay and inspect the log for the executed command and error output.

## Exit Codes

```text
0   Success or cancelled by ESC
1   Runtime error
2   Missing input value at switch time
64  Command line usage error
```
