# PG27UCDM Input Switcher

[中文说明](README.zh-CN.md)

`pg27switch` switches the input source of the ASUS ROG Swift OLED PG27UCDM with a native countdown HUD.

## Platforms

| Platform | DDC backend | Theme control |
| --- | --- | --- |
| macOS 12+ | BetterDisplay | macOS appearance |
| Windows 11 | Windows Monitor Configuration API | `system`, `dark`, `light` |

## Download

Download the latest builds from the [GitHub Releases](https://github.com/kankankankankankan/pg27switch/releases) page.

## Quick Use

macOS:

```bash
pg27switch hdmi1
pg27switch --preview dp
pg27switch --input dp --seconds 5
```

Windows PowerShell:

```powershell
& "D:\Tools\pg27switch.exe" hdmi1
& "D:\Tools\pg27switch.exe" --preview dp --seconds 3 --theme dark
& "D:\Tools\pg27switch.exe" --preview dp --seconds 3 --theme light
```

Inputs:

```text
dp, displayport          DisplayPort  15
h1, hdmi1                HDMI 1       17
h2, hdmi2                HDMI 2       18
tc, typec, usb-c, usbc   Type-C       26
```

Use `--preview` to show the HUD without changing the monitor input. The default countdown is 3 seconds. Use `--seconds 1` through `--seconds 30` to change it.

## Stream Deck

On macOS, use the launcher files generated by `macos/install.sh`, or Mac Script Runner with a Zsh command.

On Windows, create a shortcut for each input and pass the arguments in the shortcut target. Example:

```text
Target: D:\Tools\pg27switch.exe --preview dp --seconds 3 --theme dark
```

Open the shortcut with `System > Open`. The Windows executable uses the GUI subsystem, so it does not open a console window.

## Build

macOS:

```bash
xcode-select --install
./macos/build.sh
```

Windows, with the .NET 8 SDK:

```powershell
dotnet publish .\windows\PG27Switch\PG27Switch.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:IncludeAllContentForSelfExtract=true -p:PublishReadyToRun=true
```

Tagged pushes run GitHub Actions and publish both platform packages:

```bash
git tag v1.3.16
git push origin v1.3.16
```
